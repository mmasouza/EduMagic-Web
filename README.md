# EduMagic Web

[Jogar EduMagic](https://mmasouza.github.io/EduMagic-Web/)

A edição web v0.44.0 funciona diretamente no navegador e não tem limite de tempo. Inclui o EduMagic e o Color Magic, com layouts adaptados ao PC e ao celular.

O progresso é salvo no navegador. Para transferir os dados para outro dispositivo, use **Exportar backup** no aparelho de origem e **Importar backup** no destino.
